3-pass method (high ROI):
Pass 1 – read the idea, copy the code by hand, say each line's why aloud.
Pass 2 – Recall mode ON (blurred): write from the idea line only, then tap code to check.
Pass 3 – blurred, timed (≈3 min/func), no peeking until done. Fix only the lines you got wrong, rewrite those.
